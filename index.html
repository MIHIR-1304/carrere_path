04 — Wisdom

The Most Important Advice

⚡ Don't pick a specialization in 1st year. Spend the first 2–3 months exploring. Build one tiny project in each area you're curious about. Your gut will tell you more than any comparison table.

The 2–3 Month Exploration Plan

1

Month 1 — Web Dev Basics

Build a personal portfolio site in HTML/CSS/JS. No frameworks yet. Just get something live on the internet. This teaches you the fundamentals that apply everywhere.

2

Month 2 — Pick Two: AI or Cybersecurity

Try a beginner Python ML project (digit recognition with MNIST). Also try one CTF challenge on PicoCTF. See which one excites you more — the "building" side or the "breaking" side.

3

Month 3 — Cloud or App Dev

Deploy your Month 1 site to AWS Free Tier. Or build a simple mobile app with React Native. At this point, you'll know what you actually enjoy doing for hours without noticing.

Decision Framework

After 3 months of exploration, ask yourself:

  • Do I prefer building things users see? → Web Dev / App Dev / UI/UX
  • Do I prefer solving puzzles and maths? → AI/ML / Data Science
  • Do I prefer infrastructure and systems? → Cloud / DevOps
  • Do I prefer finding weaknesses and hacking? → Cybersecurity
  • Do I prefer working with data to find answers? → Data Science
